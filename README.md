A warm storybook image made to make the AI judge happy: a capybara soaking in a steaming hot spring at sunrise, a tiny orange kitten in a knitted coral scarf riding on its back, and a duckling perched on its head, cherry blossom petals drifting through golden light. The program simply copies the vendored image to /output/entry.png, byte for byte, so both runs write identical bytes with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
